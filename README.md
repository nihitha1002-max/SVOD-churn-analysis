# 🎬 SVOD Churn Prediction & Analytics System

## 📖 Overview

The **SVOD Churn Prediction & Analytics System** is an end-to-end data science project developed to predict customer churn for a Subscription Video-on-Demand (SVOD) platform.

The project leverages machine learning to identify subscribers who are likely to cancel their subscriptions, enabling businesses to implement targeted retention strategies.

The solution integrates:

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning
- SQL Data Management
- Power BI Dashboard
- Streamlit Deployment
- FastAPI API Development

---

# 🎯 Business Problem

Subscription-based entertainment platforms lose significant revenue due to customer churn.

The objective of this project is to identify customers who are likely to cancel their subscriptions and provide actionable insights that help businesses improve customer retention through data-driven decisions.

---

# 🚀 Project Objectives

- Predict customer churn using Machine Learning
- Analyze customer behavior and subscription patterns
- Identify key factors contributing to churn
- Build an interactive Power BI dashboard
- Deploy the prediction model using Streamlit and FastAPI
- Support business decision-making through analytics

The project uses an SVOD customer dataset containing subscriber information, viewing behavior, subscription details, engagement metrics, and demographic attributes.

- Viewing Activity

- Payment Information
- Customer Engagement Metrics
- Churn Status (Target Variable)

